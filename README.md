# MyPaint: 나만의 그림판

MFC 대화 상자 기반으로 만든 Windows 그림판입니다. 기본 그림판의 기능을 대부분 구현했고, 어두운 테마 UI를 입혔습니다. 나만의 기능으로 **n차 함수를 입력하면 그래프를 그려 캔버스에 넣는 "함수 그래프"** 를 추가했습니다.

---

## 나만의 기능: 함수 그래프 넣기

수학 수업 자료나 문제지를 만들 때 함수 그래프를 그림판으로 그리기는 어렵습니다. 그래서 수식만 입력하면 좌표축, 눈금, 근과 극값까지 표시한 그래프를 그려 주는 기능을 넣었습니다.

**여는 방법:** 도구 막대의 **[그래프] f(x)** 버튼, 메뉴 **이미지 → 함수 그래프 넣기**, 단축키 **Ctrl+Shift+G**

### 사용 순서
1. 수식을 입력합니다. 예시 목록에서 골라도 됩니다.
2. 오른쪽 미리 보기가 바로 바뀝니다. 아래에는 실근, 극대, 극소, y절편이 계산되어 나옵니다.
3. 범위, 크기, 선 굵기, 표시 항목을 정하고 **[그래프 넣기]** 를 누릅니다.
4. 그래프는 **떠 있는 선택 영역**으로 캔버스에 들어갑니다. 끌어서 옮기거나 핸들로 크기를 바꾼 뒤 바깥을 누르면 확정됩니다. Ctrl+Z 한 번으로 되돌립니다.

### 입력할 수 있는 수식
| 입력 | 해석 결과 |
|---|---|
| `x^3 - 3x + 1` | 3차 함수: f(x) = x³ − 3x + 1 |
| `(x-1)(x+2)^2` | 3차 함수: f(x) = x³ + 3x² − 4 (전개해서 보여 줌) |
| `y = 0.5x^4 - 2x²+1` | 4차 함수: f(x) = 0.5x⁴ − 2x² + 1 |
| `x(x-2)(x+3)/4` | 3차 함수: f(x) = 0.25x³ + 0.25x² − 1.5x |
| `3×x·x − 6` | 2차 함수: f(x) = 3x² − 6 |

- 숫자(소수), `x`, `+ - * / ^`, 괄호를 쓸 수 있습니다.
- 곱셈 기호는 생략할 수 있습니다: `2x`, `x(x+1)`, `(x-1)(x+2)`.
- 위 첨자 `²`·`³`, 기호 `×`·`÷`·`−`도 됩니다. 앞에 `y =`나 `f(x) =`를 붙여도 됩니다.
- 최고 20차까지 됩니다.
- 잘못된 입력은 이유와 위치를 빨간 글씨로 알려 줍니다. 예: "x가 들어간 식으로는 나눌 수 없습니다", "닫는 괄호 ')'가 필요합니다 (5번째 글자)".

### 설정
| 항목 | 내용 |
|---|---|
| 범위 | x 최소·최대. y는 **자동**(x 범위 안 함수값에 맞춤) 또는 직접 입력 |
| 그림 | 크기 50 ~ 4000 px, 선 굵기 1 ~ 30 px. 곡선은 **색 1**, 배경은 **색 2** |
| 표시 | 좌표축과 눈금, 격자선, 눈금·좌표 숫자, 근·극값 점, 수식, 배경 투명 |

- **배경 투명**을 켜면 곡선과 축만 기존 그림 위에 얹힙니다.
- 설정과 수식은 다음에 열 때 그대로 남아 있습니다.

### 구현 방법
| 파일 | 역할 |
|---|---|
| [`Polynomial.cpp`](MyPaint/Polynomial.cpp) | **재귀 하강 해석기**가 수식을 읽으면서 바로 다항식 계수로 계산합니다. 곱셈은 계수의 합성곱, 거듭제곱은 반복 곱셈이라 `(x-1)(x+2)^2`도 전개된 계수가 됩니다. |
| 〃 | **실근:** 도함수의 근(임계점)으로 구간을 나누면 각 구간에서 함수가 단조이므로, 부호가 바뀌는 구간은 이분법으로 찾습니다. 임계점에서 0에 닿는 중근은 따로 잡습니다. 도함수의 근은 같은 방법을 재귀로 써서 구합니다. |
| 〃 | **극값:** 임계점 양쪽에서 도함수 부호가 +→−면 극대, −→+면 극소입니다. 부호가 그대로면 변곡점이라 제외합니다. |
| [`FunctionGraph.cpp`](MyPaint/FunctionGraph.cpp) | GDI+로 안티앨리어싱해서 그립니다. 눈금 간격은 1·2·5×10ⁿ 중 화면에 알맞은 값을 고릅니다. 0이 범위 밖이면 축을 가장자리로 옮깁니다. 곡선은 그림 너비의 2배로 표본을 잡습니다. 결과는 미리 곱한 알파(PARGB) 32비트 그림이라 투명 배경을 그대로 캔버스에 얹을 수 있습니다. |
| [`FunctionGraphDlg.cpp`](MyPaint/FunctionGraphDlg.cpp) | 입력이 멈추면 150 ms 뒤 **실제 크기로** 그려 미리 보기에 줄여 보여 줍니다. 미리 보기와 넣는 그림이 같습니다. |
| [`CanvasSelection.cpp`](MyPaint/CanvasSelection.cpp) | 붙여넣기와 그래프 넣기가 같은 `InsertFloating`을 씁니다. 그래프는 보이는 영역 가운데에 놓고, 캔버스보다 크면 캔버스를 늘릴지 묻습니다. |

## 그림판 기능

### 그리기 도구
- **연필, 지우개, 채우기, 스포이트, 텍스트, 돋보기**
- **브러시 9종:** 브러시, 캘리그래피 1·2, 에어브러시, 유화, 크레용, 마커, 자연스러운 연필, 수채화. 한 획 안에서 겹쳐도 진해지지 않습니다.
- **도형 23종:**
  - 직선, 곡선(두 번 휘기), 타원, 사각형, 둥근 사각형, 다각형
  - 삼각형, 직각 삼각형, 마름모, 오각형, 육각형
  - 화살표 4종, 별 3종, 설명선 3종, 하트, 번개
- **확정 전 편집:** 도형을 그린 뒤 핸들로 크기와 위치를 고치고, 색·굵기·윤곽선·채우기를 바꿀 수 있습니다.
- **윤곽선/채우기:** 없음, 단색, 크레용, 마커, 유화, 자연스러운 연필, 수채화
- **텍스트:** 글꼴, 크기, 굵게·기울임·밑줄, 배경 투명/불투명

### 선택과 편집
- 사각형 선택, 자유형 선택, 모두 선택, 선택 영역 반전, 투명 선택(색 2를 투명하게)
- 이동(Ctrl+드래그는 복사), 방향키로 1px 이동, 핸들로 크기 조정
- 잘라내기·복사·붙여넣기(시스템 클립보드), 삭제
- 실행 취소/다시 실행: 최대 50단계, 512 MB 한도

### 이미지
- 자르기, 크기 조정 및 기울이기(백분율/픽셀, 비율 유지)
- 90°·180° 회전, 상하·좌우 대칭 (선택 영역이 있으면 선택 영역에만)
- 이미지 속성(캔버스 크기), 캔버스 크기 핸들

### 보기
- 확대/축소 12.5% ~ 800%: 상태 표시줄 슬라이더, Ctrl+휠(마우스 위치 기준), 돋보기
- 눈금자, 격자선, 전체 화면, 상태 표시줄(커서 위치, 선택 크기, 이미지 크기)

### 파일
- 열기/저장: PNG, BMP, JPEG, GIF, TIFF
- 최근 파일, 끌어다 놓기로 열기, 명령줄 인수로 열기
- 인쇄, 인쇄 미리 보기, 페이지 설정(여백, 배율, 페이지 맞춤, 가운데 정렬)
- 바탕 화면 배경으로 설정(채우기, 바둑판식, 가운데)

### UI
- **위쪽 도구 막대 + 어두운 테마.** 버튼, 드롭다운, 메뉴 줄, 상태 표시줄은 직접 그린 컨트롤입니다.
- 아이콘은 Segoe MDL2 Assets 글리프와 GDI+로 그린 아이콘입니다.
- 제목 표시줄, 팝업 메뉴, 스크롤바도 어두운 모드입니다(Windows 10 1903 이상).
- 팔레트는 기본 20색과 사용자 지정 10색입니다. 왼쪽 클릭은 색 1, 오른쪽 클릭은 색 2로 지정합니다.

## 빌드

```powershell
msbuild MyPaint.sln /t:Rebuild /p:Configuration=Release /p:Platform=x64
# → x64\Release\MyPaint.exe
```

- Visual Studio 2022, x64, C++17
- MFC는 정적 링크라서 실행 파일만으로 실행됩니다.
- 소스는 UTF-8이고 `/utf-8`로 컴파일합니다.
- GDI+, DWM, UxTheme, Shell(바탕 화면 배경)을 씁니다. 모두 Windows 기본 라이브러리입니다.

## 소스 구성

솔루션 탐색기에서는 기능별 필터로 묶여 있습니다.

| 필터 | 파일 | 내용 |
|---|---|---|
| App | `MyPaint`, `MyPaintDlg` | 앱 시작, 주 대화 상자 (명령 처리, 배치, 파일·인쇄) |
| Canvas\Core | `CanvasWnd`, `CanvasInternal.h` | 이미지 보관, 좌표·확대·스크롤, 화면 출력, 마우스 분배 |
| Canvas\Drawing Tools | `CanvasTools`, `CanvasShape`, `CanvasText` | 연필·지우개·채우기·스포이트, 도형, 텍스트 |
| Canvas\Selection and Transform | `CanvasSelection`, `CanvasTransform` | 선택·이동·클립보드, 회전·크기 조정·자르기 |
| Canvas\View | `CanvasView` | 눈금자, 격자, 합성 이미지 |
| Graphics Engine | `Shapes`, `BrushEngine`, `RasterOps`, `ImageHistory` | 도형 기하, 브러시 질감, 픽셀 연산, 실행 취소 기록 |
| UI Controls | `Theme`, `TopBar`, `PickerPopup`, `StatusStrip`, `FullScreenWnd` | 어두운 테마, 도구 막대, 드롭다운, 상태 표시줄, 전체 화면 |
| Dialogs | `ResizeSkewDlg`, `ImagePropertiesDlg` | 크기 조정 및 기울이기, 이미지 속성 |
| Printing | `Printing` | 인쇄 배치, 페이지 설정, 인쇄 미리 보기 |
| **Function Graph** | `Polynomial`, `FunctionGraph`, `FunctionGraphDlg` | **나만의 기능**: 수식 해석·근 찾기, 그래프 그리기, 대화 상자 |
| Common | `pch`, `framework.h`, `targetver.h` | 공통 헤더 |
| Resources | `Resource.h`, `MyPaint.rc`, `res\` | 메뉴, 단축키, 대화 상자, 아이콘 |

## 알려진 한계
- 레이어는 없습니다.
- 보조 대화 상자는 밝은 색입니다: 열기/저장, 색, 글꼴, 크기 조정, 인쇄 등.
- 도구 막대를 모두 보려면 창 너비가 약 1100 px(100% 배율 기준) 이상이어야 합니다.
- 다른 DPI의 모니터로 창을 옮겨도 도구 막대를 다시 배치하지 않습니다.
- 함수 그래프는 다항식만 지원합니다. 삼각함수·지수·분수 함수는 지원하지 않습니다.
