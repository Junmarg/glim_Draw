## 7. 도형

**종류(23종)**: 직선, 곡선, 타원, 사각형, 둥근 사각형, 다각형, 삼각형, 직각삼각형, 마름모, 오각형, 육각형, 화살표 4방향, 별(4/5/6각), 말풍선 3종(둥근 사각, 타원, 구름), 하트, 번개.

**핵심 동작**
1. 드래그하는 동안 **고무줄(rubber-band) 미리 보기**가 그려집니다.
2. 놓은 뒤에도 **핸들이 달린 편집 상태가 유지**되어, 크기와 위치를 바꾸거나 윤곽선/채우기/색/굵기를 바꿀 수 있습니다. 다른 곳을 클릭하면 비트맵에 확정됩니다.
3. **Shift**를 누르면 정사각형/정원으로, 직선은 45° 단위로 고정됩니다.
4. **곡선**: 직선을 그린 뒤 두 번 더 클릭/드래그해 제어점 2개를 지정합니다(3차 베지어 곡선, `PolyBezier`).
5. **다각형**: 클릭할 때마다 꼭짓점이 추가되고, 시작점을 클릭하거나 더블클릭하면 닫힙니다.
6. **윤곽선 옵션**: 없음, 단색, 크레용, 마커, 유화, 연필, 수채화.
7. **채우기 옵션**: 없음, 단색(색 2) 등. 윤곽선은 색 1, 채우기는 색 2를 씁니다.

> 구현: 도형을 `CShape` 객체(종류, 경계 사각형, 색, 스타일)로 들고 있다가 확정할 때만 래스터화하세요. 미리 보기는 "확정 비트맵 복사 → 임시 도형 그리기 → 화면 출력" 순서로 **더블 버퍼링**하면 깜박임이 없습니다.

## 8. 크기와 색

- **크기**: 선택한 도구에 따라 4단계(예: 1/3/5/8px)이고, Ctrl + 숫자 키패드 +/-로도 바꿀 수 있습니다.
- **색 1(전경색), 색 2(배경색)**: 왼쪽 버튼은 색 1, 오른쪽 버튼은 색 2를 씁니다. **모든 도구에 일관되게 적용되는 그림판의 핵심 규칙**입니다.
- **팔레트**: 기본 20색 + 사용자 지정 10칸.

## 13. 권장 아키텍처 (MFC 대화 상자 기반)

```
CPaintDlg (CDialogEx)
 ├─ 도구 패널 (CMFCButton 그룹 / 라디오 동작)
 ├─ 색 패널 (사용자 정의 CWnd: 색 1/색 2 + 팔레트)
 ├─ CCanvasWnd (CWnd)  ← 핵심
 │    ├─ m_imgDoc      : 확정 이미지 (32bpp DIBSection)
 │    ├─ m_imgOverlay  : 미리 보기/떠 있는 선택 영역
 │    ├─ m_pTool       : CTool* (상태 패턴)
 │    ├─ m_zoom, m_scroll : 좌표 변환
 │    └─ CUndoManager  : 스냅숏 스택
 └─ 상태 표시줄 (CStatusBarCtrl)

CTool (추상)  OnLButtonDown/Move/Up, OnRButton*, OnKey, DrawPreview
 ├─ CPencilTool, CBrushTool(팁 전략), CEraserTool
 ├─ CFillTool, CPickerTool, CTextTool, CMagnifierTool
 ├─ CShapeTool(CShape 계층), CCurveTool, CPolygonTool
 └─ CSelectTool(사각형/자유형)
```

**설계 핵심 3가지**
1. **`OnPaint`에서는 메모리 DC에 합성한 결과를 한 번에 `BitBlt`**하고, `OnEraseBkgnd`가 `TRUE`를 반환하게 해서 깜박임을 없앱니다.
2. **도구를 상태 패턴(`CTool`)으로 분리**하면 캔버스의 마우스 처리 코드가 단순해지고, 도구를 추가하기도 쉽습니다.

**④ 그리기 순서**
```
버튼 누름 ─▶ BeginDrag: 작업 전 이미지를 m_beforeDrag에 복사, SetCapture
   │         (연필/지우개는 바로 점을 찍음)
마우스 이동 ─▶ 연필/지우개: 이전 점과 현재 점 사이를 m_image에 직접 그림
   │          도형: 끝점만 갱신하고 화면만 다시 그림 (미리 보기)
버튼 놓음 ─▶ CommitDrag: 도형을 m_image에 그리고 m_beforeDrag를 실행 취소 기록에 넣음
취소(Esc, 반대 버튼, 마우스 캡처를 잃음) ─▶ m_beforeDrag로 되돌림
```
작업 전 이미지를 **확정할 때만** 기록에 넣기 때문에, 취소해도 다시 실행 기록이 지워지지 않습니다.

**⑤ 도구별 처리**
- **연필/직선**: 굵기가 1이면 일반 펜으로 그리고, `LineTo`가 끝점을 그리지 않으므로 `SetPixelV`로 끝점을 보충합니다. 굵기가 2 이상이면 끝이 둥근 펜을 쓰고, 길이가 0인 선은 그려지지 않으므로 원으로 점을 찍습니다.
- **사각형/타원**: `PS_INSIDEFRAME` 펜을 써서 굵어져도 드래그한 사각형 안쪽에만 그려집니다. 오른쪽과 아래쪽에 1을 더해 끝 픽셀까지 포함합니다.
- **지우개**: 두 점 사이를 1px 간격으로 보간하며 사각형을 찍습니다. 오른쪽 버튼이면 `GdiFlush()`로 GDI 작업을 먼저 반영한 뒤, 픽셀 메모리를 직접 읽어 색 1인 픽셀만 바꿉니다. 픽셀 메모리의 배치는 `0x00RRGGBB`이고 `COLORREF`는 `0x00BBGGRR`이라 `ToPixel()`로 변환합니다.
- **Shift**: tan 22.5°(약 0.414)를 기준으로 0°, 45°, 90° 중 가까운 방향을 고릅니다. 사각형과 타원은 가로세로 중 긴 쪽에 맞춥니다.

`CN_TOOL`이 필요한 이유는 도구를 바꾸는 쪽이 대화 상자만이 아니기 때문입니다. 스포이트는 색을 고른 뒤 직전 도구로 돌아가고, 붙여넣기는 선택 도구로 바뀝니다. 이렇게 캔버스가 도구를 바꾸면 대화 상자의 버튼 상태도 맞춰야 합니다.

## 캔버스는 클래스 하나를 파일 4개로 나눔

| 파일 | 담당 |
|---|---|
| [CanvasWnd.cpp](MyPaint/CanvasWnd.cpp) | 이미지 관리, 좌표 변환, 확대/스크롤, 화면 출력, 마우스·키보드 분배, 캔버스 크기 조절 |
| [CanvasTools.cpp](MyPaint/CanvasTools.cpp) | 연필, 지우개, 도형, 채우기, 스포이트 |
| [CanvasSelection.cpp](MyPaint/CanvasSelection.cpp) | 사각형 선택, 이동/복사, 클립보드 |
| [CanvasText.cpp](MyPaint/CanvasText.cpp) | 텍스트 도구, 글상자 입력 창(`CTextEdit`) |
| [CanvasInternal.h](MyPaint/CanvasInternal.h) | 네 파일이 함께 쓰는 상수(여백, 확대 단계)와 도우미(색 변환, 점선 사각형) |

도구마다 클래스를 만드는 방식(상태 패턴)도 고려했습니다. 하지만 이 단계에서는 도구들이 이미지, 기록, 색, 확대 배율을 거의 다 같이 써서, 클래스 하나를 파일만 나누는 쪽이 더 단순했습니다.

# 3. 좌표 변환과 확대/축소

## 좌표계는 두 가지
- **클라이언트 좌표**: 캔버스 창 기준 화면 픽셀입니다. 마우스 메시지가 이 좌표로 들어옵니다.
- **이미지 좌표**: 그림의 픽셀 위치입니다. 모든 그리기와 선택이 이 좌표로 동작합니다.

```
ImageOrigin()  = (여백 12 - 스크롤 x, 여백 12 - 스크롤 y)      // 이미지 (0,0)이 화면에서 놓이는 위치
ImageToClient  = 원점 + floor(이미지 좌표 × 배율)
ClientToImage  = floor((클라이언트 좌표 - 원점) ÷ 배율)
```

변환은 이 함수들([CanvasWnd.cpp](MyPaint/CanvasWnd.cpp)의 "좌표 변환" 부분)에서만 합니다. 그래서 그리기 도구들은 배율이나 스크롤을 전혀 몰라도 됩니다. `floor`(내림)를 쓰는 이유는 300% 배율에서 화면 픽셀 3개가 이미지 픽셀 1개로 정확히 대응하게 하려는 것입니다. 테스트에서 화면 (73,73)을 클릭하면 이미지 (20,20)으로 변환되는 것을 확인했습니다.

## 마우스 위치를 기준으로 확대 (`SetZoomAt`)
```
1. 기준점(마우스 위치) 아래의 이미지 좌표를 소수로 계산: ix = (기준점 - 원점) ÷ 이전 배율
2. 배율을 바꾸고 스크롤바 범위를 다시 계산
3. 그 이미지 좌표가 다시 기준점에 오도록 스크롤 위치를 정함: 스크롤 = ix × 새 배율 + 여백 - 기준점
```
Ctrl+휠은 마우스 위치를, 메뉴와 단축키는 화면 가운데를 기준점으로 씁니다. 확대 단계는 12.5%, 25%, 50%, 100%~800%(100% 단위)입니다.

# 4. 화면 출력 (`OnPaint`)

```
메모리 DC에 그리기:
 ① 작업 영역 배경색
 ② 이미지 그림자
 ③ 기본 이미지: 도형을 끄는 중이면 m_preview, 아니면 m_image   ← DrawImageScaled
 ④ 떠 있는 선택 영역이면 m_floatImage를 그 위치에               ← DrawImageScaled
 ⑤ 덧그림(DrawOverlays): 지우개 사각형, 선택 점선, 글상자 점선, 크기 핸들 또는 새 크기 점선
화면에는 BitBlt 한 번으로 출력 (깜박임 없음)
```

**`DrawImageScaled`는 화면에 보이는 부분만 늘려서 그립니다.** 800% 배율에서 800×600 이미지를 통째로 늘리면 6400×4800이 됩니다. 그래서 먼저 보이는 화면 영역을 이미지 좌표로 되돌려 필요한 원본 픽셀 범위만 구하고, 그 범위만 `StretchBlt`로 그립니다. 늘리는 방식도 배율에 따라 다릅니다.
- 확대할 때(배율 ≥ 1): `COLORONCOLOR`. 픽셀이 또렷한 사각형으로 보입니다.
- 축소할 때(배율 < 1): `HALFTONE`. 여러 픽셀의 평균을 내서 부드럽게 보입니다.

④와 ⑤는 실제 이미지가 아닙니다. 확정할 때까지는 화면에만 보입니다.

# 5. 마우스 입력 처리

마우스를 누르는 순간 무엇을 할지 정하고, 끌기가 끝날 때까지 그 작업을 `m_dragMode`로 기억합니다.

```
OnButtonDown
 ├─ 이미 끄는 중인데 반대쪽 버튼을 누름 → CancelDrag (그림판과 같은 동작)
 ├─ 글상자 입력 중 → CommitText만 하고 끝 (그 클릭으로 새 작업을 시작하지 않음)
 ├─ 크기 핸들 위 → ResizeCanvas
 └─ 도구별
     연필/지우개 → Freehand          직선/사각형/타원 → Shape
     채우기 → 즉시 DoFill            스포이트 → 즉시 DoPick
     텍스트 → TextRect               선택 → 선택 영역 안이면 MoveSelection, 밖이면 SelectRect

OnMouseMove → m_dragMode에 따라 갱신      OnButtonUp → EndDrag (확정)
Esc, 마우스 캡처를 잃음 → CancelDrag
```

| m_dragMode | 끄는 동안 | 놓을 때 | 취소할 때 |
|---|---|---|---|
| `Freehand` | `m_image`에 직접 그림 | 기록에 남김 | 시작 전 이미지로 되돌림 |
| `Shape` | `m_preview`만 갱신 | `m_image`에 그리고 기록에 남김 | 미리 보기만 버림 |
| `SelectRect` | 점선 사각형 갱신 | 선택 영역 확정 | 선택 해제 |
| `MoveSelection` | 떠 있는 그림 위치 이동 | 계속 떠 있는 상태로 둠 | 그 자리에 둠 |
| `TextRect` | 점선 사각형 | 글상자 열기 | 아무것도 안 함 |
| `ResizeCanvas` | 새 크기 점선 | 캔버스 크기 변경 | 아무것도 안 함 |

## 두 가지 "끝내기" 함수
- **`CancelOperation()`**(Esc): 끄는 중이면 취소합니다. 글상자 입력 중이면 글상자를 취소합니다. 선택 영역이 있으면 확정합니다.
- **`FinishPendingWork()`**: 끄는 중이면 취소하고, 글상자와 선택 영역은 **확정**합니다. 도구 변경, 저장, 실행 취소, 새로 만들기, 열기, 닫기 전에 부릅니다.

이 함수 덕분에 입력하던 글이나 옮기던 그림을 확정하지 않고 저장하거나 닫아서 내용을 잃는 일이 없습니다.

# 6. 기능별 동작

## 채우기: 스캔라인 영역 채우기 ([CanvasTools.cpp](MyPaint/CanvasTools.cpp)의 `ScanlineFill`)
한 점씩 스택에 넣는 단순한 방식은 800×600 영역만 칠해도 스택에 수십만 개가 쌓입니다. 그래서 가로 한 줄 단위로 칠합니다.
```
1. 스택에서 점 하나를 꺼냄
2. 그 줄에서 같은 색이 이어지는 왼쪽 끝과 오른쪽 끝을 찾아 한 번에 칠함
3. 바로 위 줄과 아래 줄의 같은 범위를 훑으며, 칠해야 할 구간이 새로 시작되는 점만 스택에 넣음
```
픽셀 메모리를 직접 다루므로 시작 전에 `GdiFlush()`로 GDI 작업을 먼저 반영합니다. 클릭한 곳이 이미 채울 색이면 아무것도 하지 않고 기록도 남기지 않습니다.

## 스포이트 (`DoPick`)
픽셀 값(`0x00RRGGBB`)을 `ToColor()`로 `COLORREF`로 바꿔 대화 상자에 알립니다. 그다음 `m_toolBeforePicker`에 저장해 둔 직전 도구로 돌아가고 `CN_TOOL`을 보냅니다.

## 도형 미리 보기
| 화면 위에 바로 그리는 방식 | 이미지 사본에 그리는 방식 (채택) |
|---|---|
| 300% 배율에서는 1px 선이 화면에서도 1px로 그려져 확정 결과와 다르게 보임 | 사본을 같은 방법으로 늘려 보여 주므로, 확대 상태에서도 확정 결과와 픽셀까지 똑같음 |

마우스가 움직일 때마다 사본 전체를 다시 복사하지는 않습니다(`UpdateShapePreview`).
```
1. 이전 도형이 있던 영역만 m_image에서 m_preview로 다시 복사 (이전 도형 지우기)
2. 새 도형을 m_preview에 그림
3. 이전 영역과 새 영역을 합친 부분만 화면 갱신
```

## 사각형 선택 ([CanvasSelection.cpp](MyPaint/CanvasSelection.cpp))
선택 영역에는 두 상태가 있습니다.

```
 [고정] 점선 테두리만 있음 ──안쪽을 끎/방향키──▶ [떠 있음] 그림을 m_floatImage로 떼어 냄
                                                   (원래 자리는 색 2로 채움, Ctrl이면 그대로 둠)
 [떠 있음] ──다른 곳 클릭/Esc/도구 변경──▶ 지금 위치에 찍고 선택 끝 (StampFloating)
 붙여넣기 ──────────────────────────────▶ [떠 있음]으로 바로 시작
```
- 떠 있는 상태에서 Ctrl을 누르고 끌면 지금 자리에 하나를 찍고 사본을 계속 옮깁니다.
- Del: 고정 상태면 그 영역을 색 2로 채우고, 떠 있는 상태면 떼어 낸 그림만 버립니다(원래 자리는 떼어 낼 때 이미 비웠기 때문).
- 떠 있는 그림이 이미지 밖으로 나가면, 확정할 때 밖으로 나간 부분은 잘립니다.

## 클립보드
- **복사**: 다른 프로그램도 대부분 읽을 수 있는 **24비트 CF_DIB**(아래→위 순서)로 올립니다. 한 줄의 바이트 수를 4의 배수로 맞추고, BGR 순서로 변환합니다.
- **붙여넣기**: `CF_BITMAP`으로 읽습니다. 다른 프로그램이 `CF_DIB`만 올려도 Windows가 `CF_BITMAP`을 자동으로 만들어 주므로 이 한 가지로 충분합니다. 그림이 캔버스보다 크면 캔버스를 늘릴지 묻고, 늘리기와 붙여넣기를 실행 취소 한 단계로 묶습니다.
- **클립보드 열기 재시도**: 클립보드 기록(Win+V) 같은 다른 프로그램이 클립보드를 잠깐 잡고 있으면 `OpenClipboard`가 바로 실패하므로, 10ms 간격으로 20번까지 다시 시도합니다.

## 텍스트 ([CanvasText.cpp](MyPaint/CanvasText.cpp))
```
클릭/드래그 → StartText: 캔버스 위에 여러 줄 편집 컨트롤을 띄움 (이미지에는 아직 아무것도 그리지 않음)
입력        → OnTextChanged: 글이 넘치면 글상자를 아래로 늘림 (DrawText로 필요한 높이 계산)
바깥 클릭   → CommitText: 같은 글꼴로 DrawText를 이미지에 한 번 그리고 기록에 남김
Esc         → CancelText: 입력 창만 숨김
```
- **글자 크기**: 그림판과 같이 96 DPI 기준으로 포인트를 픽셀로 바꿉니다(12pt = 16px). 화면 DPI 설정과 관계없이 저장된 그림 속 글자 크기는 같습니다.
- **입력 창 글꼴은 배율만큼 키움**: 300% 배율이면 48px 글꼴을 써서, 화면에서 확정 결과와 비슷한 크기로 보입니다. 배율을 바꾸거나 스크롤해도 입력 창 위치와 글꼴이 다시 계산됩니다(`UpdateTextEditPlacement`).
- **회색조 안티앨리어싱**: ClearType은 그림 속 글자 가장자리에 색 번짐을 남기므로 쓰지 않습니다.
- **키보드 처리**:
  - 입력 창에 포커스가 있으면 대화 상자가 단축키를 처리하지 않습니다(`PreTranslateMessage`). 그래서 Ctrl+C/V/Z와 Del이 그림이 아니라 글자에 적용됩니다.
  - `CTextEdit`은 Enter, Tab, Esc를 대화 상자에 빼앗기지 않게 하고, Esc를 누르면 캔버스에 취소를 요청합니다.
  - 여러 줄 편집 컨트롤은 Ctrl+A를 지원하지 않아서 직접 처리합니다.
- **캔버스에 `WS_CLIPCHILDREN`을 추가**: 캔버스가 화면을 통째로 다시 그릴 때 입력 창을 덮어쓰지 않게 하기 위해서입니다.

## 캔버스 크기 핸들
- 이미지 오른쪽 가운데, 아래 가운데, 오른쪽 아래 모서리 바깥에 7px 크기의 핸들을 그립니다. 이 자리를 확보하려고 여백을 5px에서 12px로 늘렸습니다.
- 핸들 위에서는 커서 모양이 ↔, ↕, ⤡로 바뀝니다. 끄는 동안 새 크기를 점선으로 보여 주고, 상태 표시줄에 크기가 나옵니다.
- 놓으면 `ResizeCanvasTo`가 새 크기의 이미지를 만들어 색 2로 채우고, 기존 그림을 왼쪽 위에 복사합니다. 줄이면 오른쪽과 아래가 잘립니다. 한 변의 최대 크기는 16000px입니다.

# 7. 실행 취소: 언제 기록하나

모든 기능이 같은 규칙을 따릅니다. **그림이 처음 바뀌기 직전의 이미지를 한 번만 기록합니다.**

| 작업 | 기록하는 시점 |
|---|---|
| 연필, 지우개 | 버튼을 누를 때 사본을 떠 두고, 놓을 때 기록 (취소하면 그 사본으로 되돌림) |
| 도형, 텍스트, 채우기, Del | 확정하기 직전 |
| 선택 영역 이동 | 떼어 낼 때 한 번만. 몇 번을 옮기고 확정해도 실행 취소하면 이동 전으로 한 번에 돌아감 |
| 붙여넣기 | 붙여넣기 직전 (캔버스 늘리기 포함 한 단계) |

## 다각형 계열은 "단위 좌표"로 한 번만 정의

삼각형, 별, 화살표, 하트 같은 도형은 모두 **[0,1]×[0,1] 범위의 다각형**으로 정의해 둡니다. 그릴 때는 이 좌표를 `p0`→(0,0), `p1`→(1,1)이 되도록 늘립니다.

```
화면 x = p0.x + u × (p1.x − p0.x)
화면 y = p0.y + v × (p1.y − p0.y)
```

이 방식의 장점은 세 가지입니다.
- 어떤 비율로 끌어도 그 상자에 맞게 늘어납니다.
- **거꾸로 끌면(p1이 p0보다 왼쪽이나 위) 계산식만으로 모양이 뒤집힙니다.** 따로 처리할 필요가 없습니다.
- 도형을 추가하려면 단위 좌표 목록만 만들면 됩니다.

| 도형 | 만드는 방법 |
|---|---|
| 삼각형, 마름모, 육각형, 번개 | 꼭짓점 좌표를 직접 적음 |
| 오각형 | 정오각형을 계산한 뒤 `Normalize()`로 [0,1]에 맞춤 |
| 별 4/5/6각 | 바깥/안쪽 반지름을 번갈아 쓰는 점 계산 (안쪽 비율 0.38 / 0.40 / 0.55) |
| 화살표 4방향 | 오른쪽 화살표 하나를 좌표 변환해서 만듦. 왼쪽 (1−u, v), 위 (v, 1−u), 아래 (v, u) |
| 둥근 사각형 설명선 | 모서리 4개를 호로 근사하고, 아래 변에 꼬리 점 3개를 끼워 넣음 |
| 타원형 설명선 | 타원 둘레를 따라가다가 115°~135° 구간에서 꼬리 끝점으로 빠짐 |

|---|---|---|
| 직선 | `LineTo` (길이가 0이면 원으로 점) | 끝이 둥근 펜 |
| 곡선 | `PolyBezier` (3차 베지어) | 끝이 둥근 펜 |
| 타원, 사각형, 둥근 사각형 | `Ellipse`, `Rectangle`, `RoundRect` | `PS_INSIDEFRAME` (굵어져도 드래그한 상자 안쪽에) |
| 나머지 | `Polygon` (조각마다) | 꺾이는 곳이 둥근 펜 |

- **윤곽선 = 색 1, 채우기 = 색 2**입니다. 오른쪽 버튼으로 그리면 두 색이 바뀝니다(그림판과 같음).
- 윤곽선이나 채우기를 "없음"으로 하면 각각 `NULL_PEN`, `NULL_BRUSH`를 씁니다.
- 직선과 곡선은 채울 수 없으므로, 이 둘을 고르면 윤곽선·채우기 콤보가 비활성화됩니다.

# 3. 도형 도구의 진행 단계 ([CanvasShape.cpp](MyPaint/CanvasShape.cpp))

2단계에서는 버튼을 놓는 순간 도형이 확정됐습니다. 3단계에서는 **놓은 뒤에도 편집할 수 있도록** 단계(`ShapeStage`)를 둡니다.

```
 None ──드래그──▶ Drawing ──놓음──▶ Editing ──바깥 클릭 / Esc / Enter / 도구 변경──▶ 확정(None)
                   │                 ▲   └ 핸들 드래그: 크기, 안쪽 드래그: 이동, 색·굵기·윤곽선·채우기 변경
                   │ (곡선)           │
                   ├─▶ CurveBend1 ─클릭/드래그─▶ CurveBend2 ─클릭/드래그─┘
                   │ (다각형)         │
                   └─▶ Polygon ─클릭/드래그마다 꼭짓점 추가─ 시작점 클릭 / 더블클릭 / Enter ─┘
```

## 미리 보기 방식은 2단계와 같음
확정할 때까지 도형은 `m_preview`(확정 이미지 사본)에만 그립니다. 값이 바뀔 때마다 `RefreshShapePreview()`가 직전에 도형을 그렸던 영역(`m_shapeDrawnArea`)만 원본에서 다시 복사해 지우고, 새 도형을 그립니다. 확정할 때만 `m_image`에 그리고 실행 취소 기록을 **한 번** 남깁니다. 그래서 이동·크기 조정·색 변경을 여러 번 해도 실행 취소는 한 단계입니다.

## 곡선
| 단계 | 동작 |
|---|---|
| Drawing | 처음 끄는 동안은 제어점을 양 끝에 두어 직선으로 보임 |
| CurveBend1 | 클릭하거나 끈 위치로 **제어점 두 개를 함께** 옮김 (한쪽으로 휨) |
| CurveBend2 | **두 번째 제어점만** 옮김 (S자도 만들 수 있음) |
| Enter | 휘기를 건너뛰고 바로 편집 상태로 |

## 다각형
- 첫 변은 드래그로 그리고, 그 뒤로는 클릭하거나 끌 때마다 꼭짓점을 추가합니다. 끄는 동안 마지막 꼭짓점이 따라 움직이고, Shift를 누르면 45° 단위로 고정됩니다.
- **닫는 방법**: 시작점에서 6px 안쪽을 클릭, 더블클릭, 또는 Enter.
  - 더블클릭을 받으려고 캔버스 창 클래스에 `CS_DBLCLKS`를 추가했습니다.
  - 그러면 다른 도구에서 빠른 두 번째 클릭이 더블클릭 메시지로 오는데, 이 경우는 보통 클릭으로 처리합니다(`OnLButtonDblClk`).
- 만드는 중에는 닫히지 않은 꺾은선으로 보여 주고, 닫은 뒤에 채우기가 적용됩니다.
- 닫을 때 같은 자리에 연달아 찍힌 점을 정리하고, 꼭짓점이 3개 미만이면 취소합니다(`FinishPolygon`).

## 확정 전 편집: 핸들
| 대상 | 핸들 | 끌면 |
|---|---|---|
| 직선 | 양 끝점 2개 | 그 끝점이 이동 (Shift: 45° 고정) |
| 상자 도형 | 감싸는 사각형의 모서리 4개 + 변 가운데 4개 | `p0`/`p1` 중 그 쪽에 있는 좌표가 이동. **반대편을 넘어가면 모양이 뒤집힘** |
| 점 도형 | 같은 8개 | 감싸는 사각형을 바꾸고 모든 점을 비례해서 옮김 (최소 1px 유지) |
| 안쪽 | — | 전체 이동 (직선은 선에서 몇 px 이내를 안쪽으로 봄) |

**잡는 순간 1px 튀지 않게** 했습니다. 핸들 위치를 마우스 좌표로 바로 덮어쓰지 않고, 잡은 지점에서 **움직인 거리만큼만** 가장자리를 옮깁니다(`ApplyShapeHandleDrag`). 핸들별로 커서 모양도 다릅니다(↔ ↕ ⤡ ⤢).

## 편집 중 설정을 바꾸면 바로 반영
`SetColors`, `SetSizeLevel`, `SetShapeOptions`가 `RefreshShapePreview()`를 부르기 때문에, 그린 도형을 보면서 색이나 굵기를 고를 수 있습니다. 반면 **도형 종류**를 바꾸면 편집 중인 도형을 먼저 확정합니다. 종류가 바뀌면 다른 도형이 되기 때문입니다.

## Esc와 Enter
| 상태 | Esc | Enter |
|---|---|---|
| 끄는 중 | 그 드래그만 취소 (휘기, 꼭짓점 하나, 편집 이동 단위) | — |
| 곡선/다각형을 만드는 중 | 도형 전체 취소 | 다각형 닫기, 곡선 휘기 생략 |
| 편집 중 | **확정** | 확정 |

# 4. 자유형 선택 ([CanvasSelection.cpp](MyPaint/CanvasSelection.cpp))

## 선택 영역 표현
```
m_selRect     : 경로를 감싸는 사각형 (이미지 밖은 잘라냄)
m_selPolygon  : 경로 (m_selRect 왼쪽 위 기준 상대 좌표)
m_selFreeform : 자유형인지
```
경로를 상대 좌표로 저장하므로, 선택 영역을 옮길 때는 `m_selRect`만 바꾸면 됩니다.

## 마스크 만들기 (`BuildSelectionMask`)
경로 안의 픽셀을 직접 계산하지 않고 **GDI가 칠하게** 합니다.
```
1. 선택 사각형 크기의 검은 이미지를 만듦
2. 경로를 흰색 Polygon으로 칠함 (WINDING 모드: 경로가 스스로 겹쳐도 안쪽은 모두 선택)
3. 흰 픽셀 = 선택된 픽셀
```
칠해진 픽셀이 하나도 없으면(거의 직선 경로) 선택하지 않습니다.

## 떠 있는 그림을 알파 채널로 바꿈 (2단계와 달라진 부분)
2단계의 떠 있는 그림은 사각형이라 그냥 복사하면 됐습니다. 자유형 선택은 **경로 밖이 투명**해야 합니다. 그래서 떠 있는 그림을 미리 곱한 알파(premultiplied alpha) 이미지로 바꿨습니다.

| 픽셀 | 값 |
|---|---|
| 선택 안 | `0xFF` + 원래 색 (불투명) |
| 선택 밖 | `0x00000000` (완전 투명) |
| 크기 조정으로 생긴 가장자리 | 중간 알파 (반투명) |

이 표현을 쓰는 곳이 세 군데입니다.
- **화면 표시**: `StretchBlt` 대신 `GdiAlphaBlend`(`AC_SRC_ALPHA`)로 그려서 선택 밖은 아래 그림이 비칩니다. 확대 상태에서도 그대로 동작합니다.
- **찍기**(`StampFloating`)와 **자르기**: 픽셀마다 `BlendOver(dst, src) = src + dst × (255 − a) / 255`로 합성합니다([CanvasInternal.h](MyPaint/CanvasInternal.h)).
- **클립보드 복사**: 투명한 부분은 색 2 위에 합성해서 24비트로 올립니다.

사각형 선택도 같은 코드를 씁니다. 알파가 전부 255일 뿐입니다. 그래서 사각형과 자유형을 구분하는 분기는 마스크를 만들 때 한 군데뿐입니다. 4단계의 "투명 선택"(색 2 픽셀의 알파를 0으로)도 이 구조 위에 쉽게 얹을 수 있습니다.

## 떼어 낼 때 원래 자리 처리
사각형 전체가 아니라 **마스크 안의 픽셀만** 색 2로 비웁니다. 테스트에서 삼각형 경로로 사각형 일부를 옮겼을 때, 경로 밖의 사각형 부분은 그대로 남았습니다.

# 5. 회전·대칭·크기 조정·기울이기

## 대상과 실행 취소 규칙 ([CanvasTransform.cpp](MyPaint/CanvasTransform.cpp))

| 대상 | 처리 | 실행 취소 기록 |
|---|---|---|
| 선택 영역이 있을 때 | 떼어 낸 그림(`m_floatImage`)을 변환. 위치는 왼쪽 위 기준으로 유지 | **떼어 낼 때 한 번만**. 여러 번 변환하고 확정해도 실행 취소 한 번이면 원래대로 |
| 선택 영역이 없을 때 | 이미지 전체를 변환 | 변환할 때마다 한 번 |

**자유형 선택의 경로도 같이 변환합니다.** 회전하면 점선 경로도 돌아가고, 크기를 조정하면 비례해서 바뀝니다(`FlipRotatePoint`, `SkewPoint`).

변환을 시작하기 전에 `FinishPendingWorkExceptSelection()`을 부릅니다. 글상자와 편집 중인 도형은 확정하되, 변환 대상인 선택 영역은 그대로 두는 함수입니다. 2단계의 `FinishPendingWork()`를 이 함수 + `DropSelection()`으로 나눴습니다.

## 픽셀 계산 ([RasterOps.cpp](MyPaint/RasterOps.cpp))
모든 함수는 `PixelBuffer`(너비, 높이, 32비트 픽셀 배열)를 받아 새 `PixelBuffer`를 돌려줍니다. 알파를 포함한 4채널을 똑같이 계산하므로, 일반 이미지(알파 0)와 떠 있는 그림(미리 곱한 알파)에 같은 함수를 씁니다.

**회전/대칭**: 픽셀 위치만 바꿉니다(손실 없음).

| 변환 | (x, y) → | 크기 |
|---|---|---|
| 오른쪽 90° | (h−1−y, x) | 가로·세로 바뀜 |
| 왼쪽 90° | (y, w−1−x) | 가로·세로 바뀜 |
| 180° | (w−1−x, h−1−y) | 그대로 |
| 상하 대칭 | (x, h−1−y) | 그대로 |
| 좌우 대칭 | (w−1−x, y) | 그대로 |

**크기 조정**: 가로를 먼저 바꾸고 그다음 세로를 바꿉니다(분리 가능한 필터). 한 줄을 다시 표본화하는 방식이 경우에 따라 다릅니다.
- **늘릴 때**: 새 픽셀 중심이 원본의 어디인지 구해 양옆 두 픽셀을 **선형 보간**합니다.
- **줄일 때**: 새 픽셀 하나가 덮는 원본 구간의 픽셀들을 **겹친 길이만큼 가중 평균**합니다(면적 평균). 선형 보간으로 크게 줄이면 픽셀을 건너뛰어 가는 선이 끊기는데, 이 방식은 모든 원본 픽셀이 결과에 반영됩니다.

**기울이기**: 그림판처럼 **가로로 기울인 뒤 세로로** 기울입니다.
- 가로: 각 줄을 `y × tan(각도)`만큼 옆으로 밉니다. 결과 너비는 `w + ⌈|tan|·h⌉`입니다.
- 세로: 가로로 기울인 결과의 각 열을 `x × tan(각도)`만큼 아래로 밉니다.
- 결과 픽셀마다 원본 위치를 거꾸로 계산해 가장 가까운 픽셀을 가져옵니다(역방향 매핑). 앞에서부터 밀어 넣으면 생길 수 있는 빈 구멍이 생기지 않습니다.
- 새로 생긴 빈 곳은 이미지 전체면 색 2, 선택 영역이면 투명입니다.
- 결과가 한 변 16000px를 넘으면 미리 계산해서 거절합니다(`ResizeAndSkew`가 `false`를 돌려주면 대화 상자가 안내).

## "크기 조정 및 기울이기" 대화 상자 ([ResizeSkewDlg.cpp](MyPaint/ResizeSkewDlg.cpp))
- **단위 전환**: 백분율 ↔ 픽셀을 바꾸면 입력란의 값을 새 단위로 환산해서 다시 보여 줍니다.
- **가로세로 비율 유지**: 한쪽을 바꾸면 다른 쪽을 자동으로 맞춥니다(백분율이면 같은 값, 픽셀이면 원래 비율). 코드에서 값을 넣을 때 다시 변경 알림이 오며 무한히 반복되는 것을 `m_updating` 플래그로 막습니다.
- **검사**: 크기는 1~1000% 또는 1~16000px, 기울기는 −89°~89°만 받습니다. 잘못 입력하면 그 입력란으로 포커스를 옮깁니다.

> ⚠️ **확인하지 못한 문제**: 지난 테스트에서 50% 크기 조정과 30° 기울이기를 했을 때, 결과 이미지가 예상한 400×300, 1147×600보다 작게 나왔습니다. 대화 상자의 값 전달, `Resize`/`Skew` 계산, 앞선 테스트 단계의 실행 취소 상태 중 어디가 원인인지 아직 모릅니다.

## 자르기 (`CropToSelection`)
선택한 그림(떠 있으면 떠 있는 그림)을 색 2로 채운 새 이미지 위에 합성해서, 그것을 새 이미지로 씁니다. 그래서 자유형 선택으로 자르면 경로 밖은 색 2가 됩니다. 이미 떠 있던 선택이면 떼어 낼 때 남긴 기록으로 충분하므로 기록을 더 남기지 않습니다. 단축키는 Ctrl+Shift+X입니다. 단축키 테이블이 수정 키 조합까지 정확히 비교하기 때문에 Ctrl+X(잘라내기)와 겹치지 않습니다.

# 6. 인쇄 ([Printing.cpp](MyPaint/Printing.cpp))

## 설정 보관 (`CPrintSettings`)
- 프린터 선택, 용지, 방향(`hDevMode`/`hDevNames`)과 여백(1/100 mm, 기본 10mm)을 **다음 인쇄까지 기억**합니다.
- **핸들 소유권**: 공용 대화 상자는 이 핸들을 다시 할당할 수 있습니다. 그래서 대화 상자가 닫히면 핸들을 돌려받고, 대화 상자 쪽 포인터를 `nullptr`로 비워 두 번 해제되지 않게 했습니다. 마지막 해제는 `CPrintSettings` 소멸자가 합니다.

## 한 페이지에 인쇄하는 계산 (`RenderPage`)
```
1. 장치 정보: 해상도(LOGPIXELS), 인쇄 가능 영역(HORZRES/VERTRES),
   용지 크기(PHYSICALWIDTH/HEIGHT), 용지 가장자리에서 인쇄 가능 영역까지 거리(PHYSICALOFFSET)
2. 여백(1/100 mm) → 프린터 픽셀로 변환하고, 인쇄 가능 영역 좌표로 옮김
3. 이미지 크기: 화면과 같은 크기 = 이미지 픽셀을 96 DPI로 보고 프린터 해상도로 환산
4. 여백 안에 들어가지 않으면 비율을 유지한 채 줄임 (늘리지는 않음)
5. 여백 안쪽 왼쪽 위에 StretchDIBits (32비트 위→아래 DIB를 그대로 넘김, HALFTONE)
6. 중간에 실패하면 AbortDoc으로 인쇄 작업 취소
```
인쇄하기 전에 `FinishPendingWork()`를 불러서 입력 중인 글, 편집 중인 도형, 떠 있는 선택 영역까지 인쇄에 포함합니다.

# 2. 질감 브러시 9종 ([BrushEngine.cpp](MyPaint/BrushEngine.cpp))

## 기본 원리: 자국을 경로를 따라 찍기
브러시는 "자국"(작은 모양) 하나를 정해 두고, 마우스가 지나간 경로를 따라 일정 간격으로 찍습니다.

```
Segment(from, to):
  거리 = |to − from|
  개수 = ⌈거리 ÷ 간격⌉
  i = 1..개수: from + (to − from) × i/개수 위치에 Stamp
```

간격은 브러시마다 다릅니다(`Spacing()`). 너무 넓으면 구슬처럼 끊기고, 너무 좁으면 느려집니다.

| 브러시 | 간격 |
|---|---|
| 일반 | 굵기 ÷ 4 |
| 에어브러시 | 굵기 × 0.75 (빠르게 움직여도 빈틈이 생기지 않을 만큼) |
| 크레용 | 굵기 ÷ 3 |
| 수채화 | 굵기 ÷ 5 |
| 캘리그래피, 유화, 마커, 연필 | 1px (자국 모양이 얇거나 줄무늬라서 촘촘해야 함) |

## 픽셀에 쓰는 방법 두 가지

| 방식 | 함수 | 브러시 | 동작 |
|---|---|---|---|
| **직접 쓰기** | `Put` | 일반, 캘리그래피, 에어브러시, 유화 | 픽셀을 브러시 색으로 바로 바꿈 (불투명) |
| **덮임 정도 쓰기** | `Cover` | 크레용, 마커, 자연스러운 연필, 수채화 | 아래 설명 |

**덮임 정도 쓰기**는 실제 마커처럼 **한 획 안에서는 같은 곳을 여러 번 지나가도 진해지지 않게** 하는 방법입니다.
```
Cover(x, y, 진하기):
  이 픽셀이 이번 획에서 이미 그 이상 진하게 칠해졌으면 → 무시
  아니면: 기록을 갱신하고
         픽셀 = 섞기(획을 긋기 전 픽셀, 브러시 색, 진하기)
```

핵심은 **"획을 긋기 전 픽셀"과 섞는다는 점**입니다. 지금 픽셀과 섞으면 지나갈 때마다 진해집니다. 획을 긋기 전 이미지는 실행 취소용으로 이미 떠 두는 사본(`m_beforeDrag`)을 그대로 씁니다. 그래서 메모리가 더 들지 않습니다. 테스트에서 마커로 같은 곳을 왕복해도 회색 115로 같았고, 두 번째 획을 겹치면 52로 진해졌습니다.

**덮임 기록을 조각 단위로 할당**합니다. 이미지 크기만큼 배열을 잡으면 16000×16000 이미지에서 256MB가 필요합니다. 그래서 64×64 조각으로 나눠 **실제로 칠한 곳의 조각만** 만듭니다(`std::unordered_map`). 획이 끝나면 버립니다.

## 브러시별 자국

| 브러시 | 자국 | 질감을 내는 방법 |
|---|---|---|
| **브러시** | 꽉 찬 원 (지름 = 굵기) | — |
| **캘리그래피 1 / 2** | 45° 기운 짧은 선 ("/" 또는 "\"), 2px 두께 | 펜촉과 **같은 방향**으로 그으면 자국이 겹쳐 가늘고, **수직**으로 그으면 펜촉 길이만큼 굵음. 2px로 한 이유는 대각선으로 움직일 때 격자 모양 구멍이 나지 않게 하려는 것 |
| **에어브러시** | 반지름 굵기×1.5인 원 안에 무작위 점 (반지름²/10개) | 점을 원 안에 고르게 흩뿌림(원 밖은 버림). **누르고 있으면 30ms마다 계속 뿌림**(아래 타이머 설명) |
| **유화 브러시** | 붓털 여러 개 (굵기×2개 이상) | 획을 시작할 때 붓털마다 **위치와 색조(−45~+35)를 한 번 정해 두고** 획 내내 그대로 씀 → 획 방향으로 색 줄무늬가 이어짐 |
| **크레용** | 원 | 픽셀마다 **위치로 정해지는 잡음** 값이 160 미만인 곳만 칠함 → 군데군데 빔 |
| **마커** | 세로로 긴 납작한 사각형 | 진하기 140(약 55%)으로 덮임 쓰기 |
| **자연스러운 연필** | 작은 원 (반지름 = 굵기 ÷ 4) | 진하기를 위치 잡음에 따라 120~247로 → 거친 선 |
| **수채화 브러시** | 원 | 진하기 = 110 × (1 − 0.7 × (거리/반지름)²) × 잡음 → 가운데가 가장 진하고 가장자리로 옅어짐, 얼룩 |

## 위치로 정해지는 잡음 (`GrainAt`)
```
GrainAt(x, y) = 좌표를 섞은 해시값의 하위 8비트 (0~255)
```
난수가 아니라 **좌표로 정해지는 값**이라 같은 자리는 항상 같은 값이 나옵니다. 그래서 크레용 획을 여러 번 겹쳐도 같은 자리가 계속 비어 있어서, 실제 종이 결처럼 보입니다. 난수였다면 겹칠수록 빈 곳이 메워져 질감이 사라집니다.

## 캔버스와 연결 ([CanvasTools.cpp](MyPaint/CanvasTools.cpp))
브러시는 연필·지우개와 같은 "자유선" 흐름을 그대로 탑니다. 덕분에 취소, 실행 취소, 반대쪽 버튼으로 취소하는 동작이 모두 그대로 적용됩니다.
```
버튼 누름 → BeginFreehand: 실행 취소용 사본(m_beforeDrag)을 뜨고,
            m_brushStroke.Begin(종류, 색, 굵기, 이미지 픽셀 주소, 사본 픽셀 주소, 시드)
            → Dab(누른 점)
            에어브러시면 SetTimer(30ms)
마우스 이동 → ContinueFreehand: Segment(직전 점, 현재 점)
타이머     → OnTimer: Spray(현재 위치)   // 마우스가 멈춰 있어도 계속 뿌림
버튼 놓음  → KillTimer, 사본을 실행 취소 기록에 넣음
취소       → KillTimer, 사본으로 되돌림
```
- 엔진은 이미지 픽셀 메모리에 직접 쓰므로, 쓰기 전에 `GdiFlush()`로 GDI 작업을 먼저 반영합니다.
- 각 함수가 돌려주는 바뀐 영역만 화면을 갱신합니다.
- 오른쪽 버튼으로 그리면 색 2입니다.
- 브러시 굵기는 4/8/14/20px이고, 브러시 종류를 고르면 브러시 도구로 바뀝니다.

# 3. 투명 선택

**투명 선택**을 켜면 떠 있는 그림에서 **색 2(배경색)와 같은 픽셀이 투명**해져서, 옮길 때 그 아래 그림이 보입니다(그림판과 같은 동작).

## 떠 있는 그림을 두 장으로 나눔
3단계까지는 떠 있는 그림이 `m_floatImage` 한 장이었습니다. 투명하게 만든 픽셀은 원래 색을 잃기 때문에, 그대로 두면 투명 선택을 끄거나 색 2를 바꿀 때 되돌릴 수 없습니다. 그래서 둘로 나눴습니다.

| 이미지 | 내용 | 쓰는 곳 |
|---|---|---|
| `m_floatSource` | 떼어 낸 원본 그대로 | 떼어 내기, 붙여넣기, 회전·크기 조정·기울이기는 **여기에** 적용 |
| `m_floatImage` | 원본 + 투명 선택 적용 | 화면 표시, 찍기, 복사, 자르기 |

```
RebuildFloatImage():
  m_floatImage = m_floatSource 복사
  투명 선택이면: 불투명(알파 255)이면서 색이 색 2와 같은 픽셀 → 0 (완전 투명)
```

다시 계산하는 시점은 원본이 바뀔 때(떼어 내기, 붙여넣기, 변환), 투명 선택을 켜거나 끌 때, **색 2가 바뀔 때**입니다. 3단계에서 떠 있는 그림을 알파 채널로 바꿔 두었기 때문에, 투명 선택은 "알파를 0으로 만드는 한 줄"로 끝납니다. 화면 표시(`GdiAlphaBlend`)와 찍기(`BlendOver`)는 손대지 않았습니다.

테스트에서 흰 테두리를 포함해 선택하고 검은 선 위로 옮겼을 때, 켜면 흰 부분으로 선이 보이고 끄면 흰색이 선을 덮었습니다.

# 4. 눈금자와 격자선 ([CanvasView.cpp](MyPaint/CanvasView.cpp))

## 눈금자 (Ctrl+R)

**자리 확보.** 눈금자를 켜면 좌표 원점이 20px씩 밀립니다.
```
ImageOrigin() = (눈금자 두께 + 여백 − 스크롤 x, 눈금자 두께 + 여백 − 스크롤 y)
ContentSize() 에도 눈금자 두께를 더함
```
2단계부터 좌표 변환을 `ImageOrigin()` 한 곳에 모아 두었기 때문에, 이 한 줄로 그리기, 선택, 핸들, 글상자 위치가 모두 맞춰집니다. 눈금자는 스크롤과 관계없이 위·왼쪽에 고정해서 맨 마지막에 덮어 그리고, 그림은 그 아래로 스크롤됩니다.

**눈금 간격은 배율에 맞춰 자동으로 고릅니다.**
```
큰 눈금(숫자) = {1, 2, 5, 10, 20, 50, 100, ...} 중 화면에서 50px 이상 벌어지는 가장 작은 값
작은 눈금    = 큰 눈금 ÷ 5 (또는 ÷ 2), 화면에서 5px 이상일 때만
```
100%에서는 50px마다, 800%에서는 10px마다 숫자가 붙습니다. 화면에 보이는 범위의 눈금만 계산합니다.

**세로 눈금자 숫자.** 20px 폭에 "1000" 같은 숫자를 가로로 쓸 수 없어서, 글꼴을 **90° 돌려서**(`lfEscapement = 900`) 씁니다. 돌린 글자는 기준점에서 위쪽으로 써지므로, 글자 길이만큼 아래에서 시작하게 계산합니다.

**마우스 위치 표시.** 커서가 있는 픽셀 위치를 두 눈금자에 빨간 선으로 표시합니다. 마우스가 움직이면 눈금자 영역만 다시 그립니다.

**눈금자 위 클릭은 무시하고**, 커서를 일반 화살표로 바꿉니다.

|---|---|
| 400% 이상 | 픽셀마다 (픽셀 단위 편집용) |
| 그 아래 | {2, 5, 10, 20, 50, ...} 중 칸이 화면에서 8px 이상인 가장 작은 값 |

# 5. 전체 화면 (F11)

## 보여 줄 그림: `GetCompositeImage`
화면에 보이는 그대로 보여 주되, 편집 중인 것을 **확정하지는 않습니다**.
```
결과 = (편집 중인 도형이 있으면 미리 보기 이미지, 아니면 확정 이미지) 복사
       + 떠 있는 선택 영역을 그 위치에 합성 (BlendOver)
```
전체 화면에서 돌아와도 도형은 계속 편집 중이고, 선택 영역도 떠 있는 상태 그대로입니다.

## 전체 화면 창 ([FullScreenWnd.cpp](MyPaint/FullScreenWnd.cpp))
- 주 창이 있는 **모니터 전체 크기**(`MonitorFromWindow` + `GetMonitorInfo`)의 테두리 없는 창입니다. 모니터가 여러 대여도 프로그램이 있는 쪽에 뜹니다.
- 그림은 가운데에 실제 크기로 보여 주고, 화면보다 크면 비율을 유지해 줄입니다(`HALFTONE`).
- **닫히는 경우**: 아무 키, 마우스 버튼, Alt+F4(프로그램이 아니라 전체 화면만 닫음), 다른 창으로 전환했을 때. 마지막 경우를 넣은 이유는 Alt+Tab으로 나가면 보이지 않는 전체 화면 창이 남지 않게 하려는 것입니다.
- **스스로 삭제되는 창**: `Show()`로만 만들 수 있고, 창이 닫히면 `PostNcDestroy`에서 `delete this`로 자신을 지웁니다. 대화 상자가 창 포인터를 들고 있을 필요가 없습니다.

## 단축키 충돌 방지
전체 화면 창은 대화 상자의 모달 메시지 루프 안에서 동작합니다. 그래서 거기서 누른 키도 대화 상자의 `PreTranslateMessage`를 거칩니다. 그대로 두면 전체 화면에서 누른 Ctrl+Z가 뒤의 그림을 되돌립니다. 그래서 **대화 상자 자신과 그 자식 창으로 가는 키만** 단축키로 처리하도록 조건을 추가했습니다(`::IsChild`).

## 이미지 속성 (Ctrl+E)
- 파일 경로(긴 경로는 가운데를 `...`로 줄여 표시)와 캔버스 너비·높이를 보여 줍니다.
- 크기를 바꾸면 2단계의 캔버스 크기 핸들과 같은 `ResizeCanvasTo`를 씁니다. 그림은 늘이거나 줄이지 않고 캔버스만 바뀌며, 늘어난 부분은 색 2입니다. 실행 취소할 수 있습니다.
- 1~16000px만 받습니다.

## 단축키

| Ctrl+B / I / U (글상자 입력 중) | 굵게 / 기울임 / 밑줄 | 아래 설명 |

**Ctrl+B/I/U는 글상자 안에서만 동작합니다.** 글상자에 포커스가 있으면 대화 상자가 단축키를 처리하지 않으므로, `CTextEdit::OnKeyDown`이 직접 받아서 캔버스의 `ToggleTextStyle`을 부릅니다. 이때 하나 막아야 할 것이 있습니다. Ctrl+I는 **탭 문자(9)를 만들어서**, 그냥 두면 기울임과 함께 글상자에 탭이 입력됩니다. 그래서 Ctrl을 누른 상태의 문자 2/9/21은 `OnChar`에서 버립니다. 테스트에서 실제 키 입력으로 Ctrl+B를 눌렀더니 같은 글자의 어두운 픽셀이 172개에서 316개로 늘었습니다.

# 8. 테스트와 한계

**자동 GUI 테스트 29개 중 28개 통과.** 남은 1개는 세로 눈금자 색을 확인한 지점이 마침 눈금 숫자 "250"의 글자 픽셀이었던 것입니다. 스크린숏에서 눈금자가 정상으로 그려진 것을 확인했습니다. 첫 실행에서 실패가 많았던 원인은 테스트 스크립트였습니다. PowerShell 변수 이름은 대소문자를 구분하지 않아서 `$m`이 여백 값 `$M`을 덮어썼고, 메시지 상자 글은 512자까지만 읽고 있었습니다.

**알려진 한계**
- 최소 창 높이가 약 850px라서, 세로 768px 화면에서는 왼쪽 패널 아래쪽이 잘립니다.

- 에어브러시와 유화의 무작위 배치는 획을 시작한 시각을 시드로 쓰므로, 같은 획을 다시 그려도 모양이 똑같지는 않습니다.
- 레이어/알파 채널은 구현하지 않았습니다. 이미지를 레이어 목록으로 바꾸고 실행 취소, 변환, 선택, 저장(투명 PNG)을 모두 레이어 단위로 고쳐야 하는 가장 큰 변경입니다.

## 정리 기준
- **헤더와 소스를 같은 필터에 둠**: 기본 구성("헤더 파일"/"소스 파일")은 한 기능의 `.h`와 `.cpp`가 서로 떨어져 있어서, 기능 단위로 함께 묶었습니다.
- **캔버스는 하위 필터로 나눔**: 클래스는 `CCanvasWnd` 하나지만 구현 파일이 6개라서, 파일 머리 주석에 적어 둔 구분대로 나눴습니다.

## 2. 그림판과 동작이 다르다고 느끼기 쉬운 부분
- **텍스트에서 Esc**: 여기서는 글상자가 취소되고(입력한 글이 사라짐), 그림판과 다를 수 있습니다. 내용을 잃는 쪽이라 확인해 볼 만합니다.
- **화면 크기**: 왼쪽 패널 때문에 최소 창 높이가 약 850px입니다. 그림판은 리본이 가로로 있어서 작은 화면에서도 씁니다.
- **DPI가 다른 모니터로 창을 옮길 때** 왼쪽 패널 크기를 다시 계산하지 않습니다.

## 테스트 중 찾아서 고친 결함
**질감 채우기를 쓰면 그림 전체가 도형 시작점만큼 밀려 보이는 문제**가 있었습니다.
- 원인: `CImage::GetDC()`는 여러 이미지가 함께 쓰는 캐시 DC를 빌려주는데, 돌려받을 때 DC 상태를 초기화하지 않습니다. 마스크를 그리면서 옮긴 원점이 캐시에 남아, 화면을 그릴 때 원본 이미지를 엉뚱한 위치에서 읽었습니다.
- 수정: 이런 DC의 상태를 바꾸는 세 곳(질감 채우기 마스크, 자유형 선택 마스크, 텍스트 확정)을 `SaveDC`/`RestoreDC`로 감쌌습니다. 자유형 선택 마스크의 채우기 모드도 같은 이유로 다른 도형에 영향을 줄 수 있었습니다.

## 구현 요점
- **선택 영역 반전**: 윤곽선을 "고리 여러 개"로 바꿨습니다. 이미지 테두리 고리와 원래 윤곽선을 교대 채우기(ALTERNATE)로 칠하면 원래 선택의 바깥이 됩니다. 반전한 선택도 이동, 회전, 크기 조정, 삭제, 자르기를 그대로 쓸 수 있습니다.
- **선택 핸들 크기 조정**: 핸들을 끄는 동안 항상 **잡았을 때의 원본에서** 다시 계산하므로, 여러 번 늘였다 줄여도 화질이 누적해서 나빠지지 않습니다.
- **도형 질감**: 채우기는 도형 안쪽 마스크에 브러시 질감을 적용하고, 윤곽선은 도형을 GDI 경로로 기록해 꺾은선으로 편 뒤 그 선을 따라 브러시 획을 긋습니다. 타원이나 곡선도 같은 방법으로 처리됩니다.
- **인쇄**: 인쇄와 미리 보기가 같은 배치 계산(`ComputePrintLayout`)을 써서, 미리 보기에서 본 그대로 인쇄됩니다. 그림이 넘치면 여러 장으로 나눠 인쇄합니다.

# 7. 주 대화 상자: 모든 것을 명령으로 ([MyPaintDlg.cpp](MyPaint/MyPaintDlg.cpp))

## 명령 ID 체계
예전에는 콤보 상자 선택, 라디오 버튼, 색 패널 메시지가 제각각이었습니다. 지금은 **모두 `WM_COMMAND` 하나**로 들어오고, 범위 처리기(`ON_COMMAND_RANGE`)가 받습니다.

| 범위 | 의미 | 처리기 |
|---|---|---|
| `IDC_TOOL_PENCIL` ~ `IDC_TOOL_MAGNIFIER` | 도구 10개 | `OnToolCommand` |
| `ID_BRUSH_FIRST` + 0~8 | 브러시 종류 (고르면 브러시 도구로) | `OnBrushCommand` |
| `ID_SHAPE_FIRST` + 0~22 | 도형 종류 (고르면 도형 도구로) | `OnShapeCommand` |
| `ID_OUTLINE_FIRST` / `ID_FILL_FIRST` + 0~6 | 윤곽선 / 채우기 방식 | `OnOutlineCommand` / `OnFillCommand` |
| `ID_SIZE_LEVEL_FIRST` + 0~3 | 굵기 단계 | `OnSizeLevelCommand` |
| `ID_COLOR1_FIRST` / `ID_COLOR2_FIRST` + 0~29 | 팔레트 칸 → 색 1 / 색 2 | `OnColor1Command` / `OnColor2Command` |
| `ID_COLOR_EDIT1/2`, `ID_TEXT_*_CMD` | 색 편집, 글꼴, 굵게/기울임/밑줄, 배경 투명 | 각 처리기 |

이렇게 하면 도구 막대, 드롭다운, 메뉴, 단축키가 **같은 처리기 하나**를 씁니다. 예를 들어 Ctrl+Plus와 굵기 드롭다운은 둘 다 굵기 처리기로 갑니다. 같은 명령을 테스트 스크립트도 그대로 보낼 수 있습니다.

## 표시 맞추기를 한곳에서
```cpp
BOOL CMyPaintDlg::OnCommand(WPARAM wParam, LPARAM lParam)
{
    const BOOL handled = CDialog::OnCommand(wParam, lParam);  // 처리기 실행
    SyncUi();                                                  // 도구 막대·상태 표시줄을 캔버스 상태에 맞춤
    return handled;
}
```
- 처리기마다 화면 갱신 코드를 넣지 않아도, 어떤 명령이든 끝나면 `SyncUi`가 캔버스에서 상태를 읽어 `TopBarState`로 넘깁니다.
- 캔버스가 스스로 상태를 바꾸는 경우도 있습니다. 스포이트 후 도구 복귀, 붙여넣기 후 선택 도구, 실행 취소 가능 여부 변화가 그렇고, 이때는 `CN_TOOL`/`CN_STATE` 알림에서 같은 `SyncUi`를 부릅니다.
- 색 1/색 2는 이제 대화 상자가 직접 들고 있습니다(`m_color1`, `m_color2`). 바뀌면 `ApplyColors`가 캔버스에 넘깁니다.

## 창 속성 노출
`SyncUi`와 `UpdateStatusZoom`이 현재 도구, 굵기 단계, 확대 단계를 창 속성(`SetProp`)으로 써 둡니다. 테스트 같은 자동화 도구나 접근성 도구가 다른 프로세스에서 `GetProp`으로 읽을 수 있습니다. 창이 없어질 때(`OnDestroy`) 지웁니다.
