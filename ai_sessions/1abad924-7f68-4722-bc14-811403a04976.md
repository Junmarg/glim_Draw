| `Swatch` / `Palette` | 색 1·색 2 / 팔레트 30칸 | 원 |

## 배치 (`Layout`)
- **메뉴 줄**: 메뉴 리소스(`IDR_MAIN_MENU`)의 최상위 항목 이름을 읽어 "파일(&F)"을 "파일"로 바꾸고, 글자 폭에 맞춰 버튼을 만듭니다. 메뉴 리소스를 고치면 메뉴 줄도 자동으로 바뀝니다.
- **도구 줄**: 그룹마다 항목을 왼쪽부터 놓고, 그룹 사각형과 이름을 기록합니다. 모든 크기는 `Px()`로 DPI를 반영합니다.
- **텍스트 도구 모드**: `SetState`에서 도구가 텍스트로 바뀌면 다시 배치해서, 브러시·도형·굵기 그룹 자리에 [글꼴] [B][I][U] [배경 투명] 그룹을 넣습니다.
- 배치가 끝나면 마지막 그룹의 오른쪽 끝을 `MinimumWidth()`로 알려 주고, 대화 상자가 그 값을 최소 창 너비로 씁니다.

## 상태 표시
도구 막대는 캔버스를 모릅니다. 대화 상자가 `TopBarState`(현재 도구, 브러시, 도형, 윤곽선/채우기, 굵기, 색, 선택 유무, 실행 취소 가능 여부, 글꼴 이름과 굵게/기울임/밑줄)를 넘기면 그것으로 그립니다.
- `IsActive`: 선택된 도구, 지금 고른 도형, 켜진 B/I/U → 밝은 바탕 + 아래쪽 파란 강조 막대
- `IsEnabled`: 실행 취소/다시 실행(기록 유무), 자르기(선택 유무), 굵기(굵기를 쓰는 도구인지), 채우기(직선·곡선이 아닌지) → 끄면 흐린 색
- `ItemIcon`: 선택 버튼은 지금 고른 방식(사각형/자유형)의 아이콘

# 6. 상태 표시줄 ([StatusStrip.cpp](MyPaint/StatusStrip.cpp))

```
[⇱ 120, 45px] [⬚ 80×60px] [▭ 800×600px] [안내 ……………………] [−] ──●── [+] 100%
```

- 칸마다 아이콘과 글자를 그리고, 글자가 같으면 다시 그리지 않습니다(`SetField`).

# 7. 주 대화 상자: 모든 것을 명령으로 ([MyPaintDlg.cpp](MyPaint/MyPaintDlg.cpp))

## 명령 ID 체계
예전에는 콤보 상자 선택, 라디오 버튼, 색 패널 메시지가 제각각이었습니다. 지금은 **모두 `WM_COMMAND` 하나**로 들어오고, 범위 처리기(`ON_COMMAND_RANGE`)가 받습니다.

| 범위 | 의미 | 처리기 |
|---|---|---|
| `IDC_TOOL_PENCIL` ~ `IDC_TOOL_MAGNIFIER` | 도구 10개 | `OnToolCommand` |
| `ID_BRUSH_FIRST` + 0~8 | 브러시 종류 (고르면 브러시 도구로) | `OnBrushCommand` |
| `ID_SHAPE_FIRST` + 0~22 | 도형 종류 (고르면 도형 도구로) | `OnShapeCommand` |
| `ID_OUTLINE_FIRST` / `ID_FILL_FIRST` + 0~6 | 윤곽선 / 채우기 방식 | `OnOutlineCommand` / `OnFillCommand` |
| `ID_SIZE_LEVEL_FIRST` + 0~3 | 굵기 단계 | `OnSizeLevelCommand` |
| `ID_COLOR1_FIRST` / `ID_COLOR2_FIRST` + 0~29 | 팔레트 칸 → 색 1 / 색 2 | `OnColor1Command` / `OnColor2Command` |
| `ID_COLOR_EDIT1/2`, `ID_TEXT_*_CMD` | 색 편집, 글꼴, 굵게/기울임/밑줄, 배경 투명 | 각 처리기 |

이렇게 하면 도구 막대, 드롭다운, 메뉴, 단축키가 **같은 처리기 하나**를 씁니다. 예를 들어 Ctrl+Plus와 굵기 드롭다운은 둘 다 굵기 처리기로 갑니다. 같은 명령을 테스트 스크립트도 그대로 보낼 수 있습니다.

## 표시 맞추기를 한곳에서
```cpp
BOOL CMyPaintDlg::OnCommand(WPARAM wParam, LPARAM lParam)
{
    const BOOL handled = CDialog::OnCommand(wParam, lParam);  // 처리기 실행
    SyncUi();                                                  // 도구 막대·상태 표시줄을 캔버스 상태에 맞춤
    return handled;
}
```
- 처리기마다 화면 갱신 코드를 넣지 않아도, 어떤 명령이든 끝나면 `SyncUi`가 캔버스에서 상태를 읽어 `TopBarState`로 넘깁니다.
- 캔버스가 스스로 상태를 바꾸는 경우도 있습니다. 스포이트 후 도구 복귀, 붙여넣기 후 선택 도구, 실행 취소 가능 여부 변화가 그렇고, 이때는 `CN_TOOL`/`CN_STATE` 알림에서 같은 `SyncUi`를 부릅니다.
- 색 1/색 2는 이제 대화 상자가 직접 들고 있습니다(`m_color1`, `m_color2`). 바뀌면 `ApplyColors`가 캔버스에 넘깁니다.

## 창 속성 노출
`SyncUi`와 `UpdateStatusZoom`이 현재 도구, 굵기 단계, 확대 단계를 창 속성(`SetProp`)으로 써 둡니다. 테스트 같은 자동화 도구나 접근성 도구가 다른 프로세스에서 `GetProp`으로 읽을 수 있습니다. 창이 없어질 때(`OnDestroy`) 지웁니다.

## 사용법
- **여는 방법:** 이미지 메뉴의 "함수 그래프 넣기", **Ctrl+Shift+G**, 도구 막대의 새 **[그래프] f(x)** 그룹 중 하나를 씁니다.
- **수식 입력:** `x^3 - 3x + 1`, `(x-1)(x+2)^2`, `y = 0.5x^4 - 2x²+1`처럼 씁니다. 곱셈 기호 생략, 괄호, `²`·`³`, `×`·`÷`·`−`도 됩니다. 콤보 상자에 예시 수식 7개가 있습니다.
- **해석 결과:** 수식을 전개해 "3차 함수: f(x) = x³ + 3x² − 4"처럼 보여 줍니다. 범위 안의 **실근, 극대·극소, y절편**도 계산해 목록으로 보여 줍니다.
- **설정:** x 범위, y 범위(자동 또는 직접), 그림 크기, 선 굵기를 정합니다. 축·격자·숫자·근과 극값 점·수식·배경 투명은 켜고 끌 수 있습니다.
- **색:** 곡선은 색 1, 배경은 색 2입니다.
- **미리 보기:** 입력을 고치면 바로 다시 그립니다. 실제로 넣을 그림을 줄여서 보여 주므로 결과와 같습니다.
- **넣은 뒤:** 그래프는 떠 있는 선택 영역으로 들어갑니다. 붙여넣은 그림처럼 옮기고 크기를 바꿀 수 있고, Ctrl+Z 한 번으로 되돌립니다. 설정과 수식은 다음에 열 때 그대로 남아 있습니다.
